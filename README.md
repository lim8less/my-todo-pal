# My Todo Pal

Build a modern Todo application.

Use my company's Internal Database Platform as the backend.

Backend API:

https://professed-endurance-agent.ngrok-free.dev/

API Documentation (OpenAPI):

https://professed-endurance-agent.ngrok-free.dev/openapi.json

Application Name:

Todo Manager

Requirements:

- Create, edit, and delete tasks

- Mark tasks as completed

- Search and filter tasks

- Automatically create the project, provision the database, and initialize the required tables if they do not already exist

- Store all data using the Internal Database Platform

- Use only the platform's REST APIs

- Do not use Supabase, Firebase, or any other backend service

Create a clean, responsive UI using TypeScript.
